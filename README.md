# Ромашка: бэкенд интернет-магазина

Учебный проект для семинара 4 курса по ИИ-агентам. Каталог, корзина с промокодами, доставка и история заказов. Только стандартная библиотека Python 3.11, внешних зависимостей нет.

## Устройство

| Модуль | Что делает |
|---|---|
| `shop/money.py` | деньги в копейках: показ суммы, скидка в процентах |
| `shop/catalog.py` | товары и поиск по названию |
| `shop/cart.py` | корзина, промокоды `SAVE10` и `SAVE15`, бесплатная доставка от 3000 ₽ |
| `shop/delivery.py` | дата отправки: до 14:00 в тот же рабочий день, склад не работает в выходные |
| `shop/orders.py` | история заказов от новых к старым |

## Как запустить тесты

Ничего ставить не нужно, тесты написаны на `unittest`:

    python -m unittest discover -s tests

Из корня репозитория. Если удобнее `pytest`, он тоже их найдёт, но в зависимостях проекта его нет.

## Как предлагать исправления

1. Ветка от `main`, название `fix/issue-<номер>`
2. Перед исправлением тест, который воспроизводит ошибку: файл `tests/test_issue_<номер>.py`. Без исправления он падает, с исправлением проходит
3. Существующие тесты не меняем: они описывают поведение, на которое уже рассчитывают
4. В описании пулл-реквеста строка `Fixes #<номер>`, чтобы задача закрылась после слияния
